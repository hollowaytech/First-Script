# First-Script
My first ever script created in Windows PowerShell.
# Features ⚙️
- Input and output systems (Read/Write-Host)
- Text colors (ForegroundColor)
- Variables and variable passing ($<variable>)
# How to execute 👇🚨
## Steps:
- Step 1: Make sure you have Windows PowerShell
- Step 2: Download the file 'firstscript.ps1' to your computer
- Step 3: Open PowerShell as administrator
- Step 4: Go to directory using 'cd' command
- Step 5: Type command 'Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass'
- Step 6: Type command '.\firstscript.ps1'
- Step 7: Watch it run!!!
